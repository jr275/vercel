# HEAD-001 Procurement Checklist

One copy per vendor. A person fills it in. Nothing here sends, signs or pays anything: those steps are always taken by a person, and not before every box in the relevant block is ticked.

## Evidence levels

| Level | Meaning |
|---|---|
| **VERIFIED** | We saw it ourselves: the portfolio close-ups, a speaking video of one of their characters, and we ran a rig file of theirs through the validator (or the vendor's own file for the claim) |
| **PARTIALLY VERIFIED** | The vendor exists and the services are corroborated by their own page text or an independent article. We have not seen the portfolio work, the speaking video or a rig file |
| **UNVERIFIED** | A claim we could not corroborate, or no vendor site found |

A marketing description is never evidence of quality. `UNKNOWN` is a valid answer for any line; a made-up value is not.

## Stop conditions

Any one of these ends the vendor's candidacy for HEAD-001:

- cannot or will not show a character speaking, in close-up, in one take
- needs photographs or a scan of a real person as the face source
- refuses full rights, source files or the originality declaration
- cannot deliver a standalone GLB, or a conversion step we can contract separately
- will not fix the price and the number of revisions
- a hidden licence or runtime dependency that cannot be removed

## Phase 0 gate (to move to Phase 1)

All of these, written down by the reviewers:

- [ ] visual identity approved
- [ ] face approved
- [ ] executive presence approved
- [ ] no real-person likeness (likeness test run)
- [ ] visual DNA preserved
- [ ] speaking test acceptable, when available (mandatory before Phase 1 acceptance)
- [ ] artist accepts the technical requirements
- [ ] IP terms acceptable

If the face is not Vera: **REJECT**. Do not try to fix a wrong facial identity later.
